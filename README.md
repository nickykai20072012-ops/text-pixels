# Text Pixels

Turn any video into coloured random characters, on the whole frame, only on the person, or on everything except the person.

**Live site:** https://nickykai20072012-ops.github.io/text-pixels/

## What it does
- Each block of pixels becomes a random character in that block's colour.
- Sliders for character size, brightness, shuffle speed, background and character set.
- Person modes use on-device models (Robust Video Matting for the body, MoveNet for arms, hands and feet).
- Export: whole-frame mode records in real time with audio; person modes render frame by frame (silent MP4, line it up with the original audio in your editor).

Everything runs in the browser. Videos are never uploaded.
